# Thư mục template

Đặt ảnh PNG chụp từ game ở đây (dùng tab **Công cụ** để chụp cho chính xác).

| File                       | Dùng để                                         |
|----------------------------|-------------------------------------------------|
| `slot_a_card.png`          | Màn hình chọn nhân vật: chụp **cả thẻ Slot A** (từ chữ "SLOT A" xuống hết nút SELECT). Tool click vào nút SELECT ở đáy thẻ |
| `join_community_button.png`| Nút xanh **Join Community** trên popup "Join AoTR" hiện ra sau khi chọn slot |
| `lobby_play_button.png`    | Menu chính: chụp chữ **PLAY kèm một phần chữ CUSTOMIZATION** ngay dưới (để không nhầm với ô PLAY trong lobby). Dùng để nhận biết menu chính **và** để bấm PLAY |
| `lobby_card.png`           | Sau khi bấm PLAY: chụp **ô LOBBY** (cả ô có chữ LOBBY, đừng lẫn ô TRADE) |
| `mission_play_button.png`  | Trong lobby: ô **PLAY** lớn (khung viền cam, dòng N/A phía trên) |
| `missions_card.png`        | Thẻ **MISSIONS** (chụp tiêu đề MISSIONS kèm phần trên của hình) |
| `create_button.png`        | Nút **CREATE** (vàng) để tạo phòng nhiệm vụ |
| `forest_map.png`           | Map **FOREST**: chỉ chụp chữ FOREST, **không** lấy dòng "REWARD BOOST (mm:ss)" vì đồng hồ thay đổi |
| `mission_hud.png`          | Nhận biết đang trong nhiệm vụ (thanh máu/gas...)|
| `reward_screen.png`        | Nhận biết màn hình thưởng (kết thúc lượt)       |
| `disconnected_dialog.png`  | Nhận biết hộp thoại mất kết nối                 |
| `start_button.png`, `retry_button.png`, `continue_button.png`, `reconnect_button.png`, `close_button.png` | Nút được macro bấm |
| `items/<tên>.png`          | Icon vật phẩm để đếm trên màn hình thưởng       |

Mẹo: chụp vùng nhỏ, đặc trưng, không chứa số thay đổi (ví dụ chữ "REWARDS"
thay vì cả màn hình). Chụp tất cả template ở **cùng một kích thước cửa sổ**.
